## 3. Khởi chạy dự án

### Bước 1: Chạy Backend và Database
Mở Terminal tại thư mục gốc dự án và chạy:
```bash
docker compose up --build -d
```

### Bước 2: Chạy ứng dụng Android
Mở Android Studio, chọn thư mục `Android` và nhấn **Run** để mở ứng dụng lên máy ảo.
